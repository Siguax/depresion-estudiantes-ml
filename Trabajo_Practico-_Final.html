  • id: Identificación única de cada estudiante en la base de datos.

  • Gender: Género del estudiante.

  • Age: Edad del estudiante en años.

  • City: Ciudad o región de residencia del estudiante.

  • Profession: Profesión u ocupación del estudiante.

  • Work Pressure: Mide el nivel de presión que experimenta el estudiante en sus responsabilidades laborales (en caso de que trabaje).

  • CGPA: Es el promedio de calificaciones acumulativas (Cumulative Grade Point Average), que refleja el rendimiento académico general del estudiante.

  • Study Satisfaction: Indica el nivel de satisfacción del estudiante con sus estudios.

  • Job Satisfaction: Indica el nivel de satisfacción del estudiante en su área laboral (en caso de que trabaje).

  • Sleep Duration: Promedio de horas que duerme por día.

  • Dietary Habits: Hábitos alimenticios del estudiante.

  • Degree: Nivel de estudio actual o título académico que cursa.

  • Have you ever had suicidal thoughts: Indica si el estudiante ha tenido pensamientos suicidas alguna vez.

  • Work/study hours: Cantidad de horas dedicadas al estudio o trabajo.

  • Financial stress: Mide el nivel de estrés debido a presiones financieras.

  • Family History of Mental Illness: Indica si hay antecedentes familiares de enfermedades mentales.

  • Depression: Muestra si el estudiante presenta depresión (0 = No depresivo, 1 = Depresivo). Esta es la variable objetivo (a predecir).

Preprocesamiento de datos

Aquí remuevo las variables que no son relevantes para el análisis y convierto la variable objetivo (Depression) a factor

# En la variable profesion - Agrupo las categorias en donde hay solo una profesion bajo la categoria de Other y recodifico los #niveles: 1 = "No depresivo", 2 = "Depresivo"
depre <- depre_raw %>%
    mutate(
    Profession = fct_collapse(Profession,
      Other = c('Civil Engineer', 'Educational Consultant', 'UX/UI Designer',
                'Entrepreneur', 'Lawyer', 'Manager', 'Architect',
                'Chef', 'Doctor', 'Pharmacist', 'Content Writer',
                'Digital Marketer')
    ) 
    )%>% 
  select(-City) %>% 
    mutate(
    Depression = factor(Depression,
                        levels = c(1, 0),
                        labels = c("no_depresivo", "depresivo")))

Receta

Preprocesamos los datos para el modelo de Machine Learning.

logistic_recipe <-
  recipe(formula = Depression ~ ., data = depre_train) %>%
  update_role(id, new_role = "id") %>%
  step_unknown(all_nominal_predictors()) %>%
  step_downsample(Depression)%>%
  step_other(Profession, threshold = 0.01, other = "Other")

Modelo

El algoritmo a utilizar es el de regresión logística binomial, que clasifica la variable dependiente en dos categorías: Depresivo y No depresivo.

logistic_spec <- logistic_reg() %>%
  set_mode("classification")

Workflow

log_workflow <- workflow() %>%
  add_recipe(logistic_recipe) %>%
  add_model(logistic_spec)

Entrenamiento del algoritmo

doParallel::registerDoParallel()
set.seed(123)
logistic_rs <-
  fit_resamples(log_workflow,
    resamples = depre_folds,
    control = control_resamples(save_pred = TRUE)
  )
